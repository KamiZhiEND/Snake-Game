# 🐍 Classic Snake Game

A modern, fully responsive implementation of the classic Snake arcade game built with vanilla HTML5, CSS, and JavaScript. Experience the nostalgia with smooth gameplay, vibrant graphics, and intuitive controls that work on both desktop and mobile devices.


## ✨ Features

- **Classic Gameplay** - Control a snake, eat apples to grow longer, and avoid colliding with walls or yourself
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Multiple Control Options**:
    - ⌨️ Keyboard arrows (desktop)
    - 🖱️ On-screen buttons (mobile/touch)
    - 👆 Swipe gestures (touch devices)
- **Score Tracking** - Persistent high score saved in your browser's localStorage
- **Visual Polish** - Gradient snake body, animated food with shading, and smooth grid lines
- **Game States** - Win condition (fill the entire board) and game over states with clear messaging
- **Performance Optimized** - Smooth 130ms game loop with efficient collision detection

## 🎯 How to Play

1. **Objective**: Eat red apples to grow your snake and increase your score
2. **Control**: Guide the snake using arrow keys, on-screen buttons, or swipe gestures
3. **Rules**:
    - Each apple increases your score by 1
    - The snake grows longer with each apple eaten
    - Game ends if you hit the wall or your own tail
    - Win by filling the entire game board (20x20 grid)
4. **Restart**: Click the RESTART button or press 'R' key at any time

## 🛠️ Technologies Used

- **HTML5** - Canvas element for game rendering
- **CSS3** - Modern styling with gradients, shadows, and responsive layouts
- **JavaScript (ES6+)** - Game logic, collision detection, and event handling
